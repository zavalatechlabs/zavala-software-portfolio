# Mobile Fitness Tracker

A comprehensive fitness tracking mobile app built with React Native and Expo, featuring workout logging, progress tracking, and AI-powered personalized recommendations.

## Problem

Gym-goers and fitness enthusiasts struggle to track workouts consistently, monitor progress over time, and maintain motivation without personalized guidance.

## Solution

Created a mobile-first fitness app that provides:
- **Easy Workout Logging:** Quick exercise entry with exercise library
- **Progress Visualization:** Charts and graphs showing strength gains
- **Smart Recommendations:** AI-suggested workouts based on history
- **Social Features:** Share achievements and compete with friends

## Tech Stack

### Mobile
- **React Native:** Cross-platform iOS and Android development
- **Expo:** Managed workflow with OTA updates
- **TypeScript:** Type-safe mobile development
- **Redux Toolkit:** Global state management
- **React Navigation:** Native-feeling navigation

### Backend
- **Firebase:** Backend-as-a-Service platform
  - **Firestore:** NoSQL database for user data
  - **Authentication:** Email, Google, Apple sign-in
  - **Storage:** Exercise images and profile photos
  - **Cloud Functions:** Serverless backend logic

## Key Features

### Workout Tracking
- **Exercise Library:** 300+ exercises with animations
- **Custom Workouts:** Build personalized routines
- **Rest Timer:** Countdown with audio alerts
- **Plate Calculator:** Barbell loading helper
- **Rep/Weight History:** View previous performance

### Progress Monitoring
- **Strength Progression:** Track 1RM and volume over time
- **Body Measurements:** Weight, body fat %, measurements
- **Progress Photos:** Compare physique changes
- **Personal Records:** Celebrate new PRs
- **Workout Streaks:** Maintain consistency

### Social Features
- **Friend Workouts:** See what friends are lifting
- **Leaderboards:** Compete on monthly volume
- **Achievements:** Unlock badges and milestones
- **Workout Sharing:** Post PRs to social feeds
