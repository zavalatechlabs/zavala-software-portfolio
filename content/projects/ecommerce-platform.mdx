# E-commerce Platform

A comprehensive e-commerce solution built with modern web technologies, featuring secure payments, inventory management, and a seamless user experience.

## Problem

Small businesses need affordable, customizable e-commerce solutions that can handle complex product catalogs, secure payments, and inventory tracking without the overhead of enterprise platforms.

## Solution

Built a lightweight yet powerful e-commerce platform that provides:
- **Secure Checkout:** Stripe integration with PCI-compliant payment processing
- **Real-time Inventory:** Live stock tracking with automatic reorder notifications
- **Admin Dashboard:** Comprehensive analytics and product management
- **Mobile-First Design:** Responsive interface optimized for all devices

### Stripe Integration
```typescript
export async function createCheckoutSession(items: CartItem[]) {
  const session = await stripe.checkout.sessions.create({
    payment_method_types: ['card'],
    line_items: items.map(item => ({
      price_data: {
        currency: 'usd',
        product_data: { name: item.name },
        unit_amount: Math.round(item.price * 100),
      },
      quantity: item.quantity,
    })),
    mode: 'payment',
    success_url: `${process.env.NEXT_PUBLIC_URL}/checkout/success`,
    cancel_url: `${process.env.NEXT_PUBLIC_URL}/cart`,
  })
  
  return session
}
```

## Challenges & Solutions

### Challenge: Race Conditions in Inventory
**Problem:** Multiple simultaneous purchases could oversell inventory.  
**Solution:** Implemented database transactions with row-level locking in Prisma to ensure atomic inventory updates.

### Challenge: Image Loading Performance
**Problem:** Product pages with multiple high-res images had slow initial load times.  
**Solution:** Integrated Cloudinary for automatic format conversion (WebP/AVIF), responsive image generation, and progressive loading.

### Challenge: Cart Persistence
**Problem:** Users lost cart contents when switching devices or clearing cookies.  
**Solution:** Hybrid approach - guest carts stored in localStorage with server-side persistence for authenticated users.
